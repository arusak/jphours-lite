# Estimate the Current phase title from container width

The Current phase title was visibly undersized on a Realme 8 Chromium PWA, but the device-specific cause of the measured fitting remains unconfirmed. Use the accepted estimate `max(16, min(48, W / (0.6 * N)))` in CSS pixels, where `W` is the `.sessionHeading` content-box inline size and `N = max(1, Array.from(title).length)` counts supplied Unicode code points, including spaces. `SessionTitle` derives the denominator during rendering; CSS container units resolve the current width, replacing runtime geometry fitting, layout effects, and the resize observer, with a viewport-width fallback for browsers lacking container units.

Preserve the full title text in its semantic `h1`, the `56px` title area, balanced wrapping, and bounded overflow with a static three-line clamp. Average glyph width is a deliberate approximation: wide glyphs may wrap or clip, and multi-code-point graphemes may be undersized; the fixed height and clamp protect Duration and Timer Ring layout rather than guarantee complete visibility for every title. Revisit fitting only if observed clipping makes this policy insufficient.
