# Derive empty Routine hints from saved entry content

The blank Routine factory and hint eligibility share one Exercise template: Practice, 100 BPM, and 300 seconds. Eligibility compares all current Exercise content fields while ignoring generated identities, Routine name, settings, and timestamps. This keeps imported or reopened matching Routines equivalent to newly created ones without onboarding metadata or storage changes.

Hints follow committed Routine entries, so saving different content hides them and restoring the template shows them again; opening or cancelling a draft changes nothing. The overlay is passive, with readable labels and decorative arrows anchored to explicit control refs. Individual annotations disappear while their targets are hidden or offscreen, without changing content eligibility or dismissing the other hints.

Hint presentation is tuned in `RoutineHints/routine-hint-config.ts`: shared defaults and a single per-hint map own label copy, placement, target attachment, and arrow geometry. The observation hook measures the browser state once per refresh; the layout module consumes those measurements without browser dependencies. This keeps tuning local and lets tests exercise configuration and layout together, while retaining hook coverage for browser updates and cleanup. Labels size to their text and CSS, including borders. Layout measures their rendered width and height and observes changes to those dimensions; it uses the same measurements for placement and arrow attachment rather than imposing dimensions from configuration. Labels that exceed the available horizontal space are omitted.

All hints hide while Routine settings are expanded and return when settings collapse. The geometry observer includes target ancestors up to the editor so disclosure resizing cannot leave arrows at stale positions, even when target sizes stay unchanged.
