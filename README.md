# Rhythm Practice Trainer

An offline-capable PWA prototype for building and running rhythm practice routines.

## Features

- Create, edit, reorder, and persist exercises locally.
- Timed paced, timed free, and open-ended exercise modes.
- Audio-clock metronome, warning and completion cues.
- Break generation, countdowns, pause/resume, skip, and stop controls.
- PWA manifest, application-shell caching, wake-lock support, and pause-on-background behaviour.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run build
npm test
npm run lint
```
